# テトリスの管理人 II

AIプレイヤーが作ってしまう崩れた盤面を、管理人であるプレイヤーが現場スキルで立て直すテトリス管理ゲームです。

プレイヤーはテトリミノを直接操作しません。下手なAIの失敗を観察し、ミストンたちの介入で穴・段差・偏りを整えます。ステージ終了時は撤去数と盤面へ戻した搬入数の「管理バランス」が評価されます。

## Prototype 1

- 10×20盤面とAIの自動配置
- 意図的に穴、段差、偏りを作る `MistakeAI`
- 介入しない限りAIは危険な配置を続け、現場はゲームオーバーへ向かう
- 現場危険度の診断と表示
- ミストンの撤去・再施工と補修材管理
- 各ステージは、AIの失敗で段差や穴が残った初期盤面から復旧開始
- アストンの優先撤去分析（AIを2秒停止）
- Stage 1からStage 15までの段階的な復旧現場
- 各ステージをクリアすると、より高速でAIのミスも深刻になる次の現場が解放
- ミントンの資材搬入（補修材を2個届ける。使用後はAI 3手分の準備時間）
- 管理バランス、スキルアップブロック、特殊ゲージ、ライン消去演出

3人同時必殺、ランダムイベント、セーブ機能はPrototype 2以降の対象です。

## 起動

```bash
npm install
npm run dev
```

起動後にターミナルへ表示されるURLを開いてください。

```bash
npm run build
```

`dist/` に静的サイトが生成されます。Vite構成のためVercel、GitHub Pagesなどへデプロイできます。

## 操作

- `現場へ入る` → `復旧研修 01` で開始
- `撤去`：連続モード。盤面の露出した固定ブロックを続けて選び、補修材を1個ずつ回収する。全ステージで最大3個、上限に達したら再施工で使うまで撤去できない
- `再施工`：連続モード。補修材を1個ずつ使い、下に支えがある空きマスへ続けて補修ブロックを置く。補修材がなくなるか、もう一度ボタンを押すと解除
- `資材搬入`：ミントンが再施工に使う補修ブロックを最大2個届ける。保管上限は全ステージで3個、使用後はAIが3ブロック置くまで再使用できない
- `優先撤去分析`：AIを2秒止め、優先して撤去すべき露出ブロックを最大3か所表示する。この間に必殺技を使うと、表示した最大3か所だけを撤去する
- `緊急復旧工事`：特殊ゲージ100%で発動。通常は露出したブロックを最大5個撤去する。3人を1回ずつ強化すると通常撤去数が6個になる
- `スキルアップ確認`：プレイ中にキャラクターカードを長押しする。短いタップでは確認画面を開かない

スキルを使った後だけ、AIは短時間の「回復期間」に入り、消去しやすい配置を選びます。放置しても勝てないため、危険な場所へ継続的に介入してください。
